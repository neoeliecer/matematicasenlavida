# Matemáticas en la Vida

Aprende las matemáticas del liceo y la universidad conectadas con el mundo real.

## Estructura del Proyecto

```
matematicasdelavida/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos CSS
├── js/
│   └── main.js         # JavaScript (menú, animaciones)
└── img/                # Imágenes (por agregar)
```

## Desarrollo Local

Simplemente abre `index.html` en tu navegador.

## GitHub Pages

El sitio se despliega automáticamente desde la rama `main` en:
